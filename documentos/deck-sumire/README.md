## 📋 Estrutura do Projeto

```

│

│   ├── analise-produtos.md (catálogo, marcas, faixas de preço)
│   └── ferramentas-e-metricas.md (dados coletados de cada ferramenta)
│
└── 03-documentos-finais/
    └── deck-aprendizados-sumire.md (DOCUMENTO PRINCIPAL consolidado)
```

---

## 🚀 Como Usar Esta Estrutura

### 1. Comece pelo Plano de Trabalho
Abra o arquivo `plano-de-trabalho.md` e siga o checklist de 7 fases:
- ✅ Marque cada item conforme for concluindo
- 📝 Salve dados brutos nas pastas correspondentes
- 📊 Documente métricas em `ferramentas-e-metricas.md`

### 2. Organize os Dados Coletados

**Durante a pesquisa, salve:**
- Screenshots do site → `01-dados-brutos/capturas-site/`
- Prints de Instagram/redes → `01-dados-brutos/prints-redes-sociais/`
- PDFs de notícias → `01-dados-brutos/artigos-e-noticias/`
- Dados de concorrentes → `01-dados-brutos/dados-competidores/`

### 3. Preencha as Análises Específicas

À medida que coleta informações, atualize os arquivos em `02-analises/`:
- `analise-marca.md` - Dados corporativos, história, CNPJ
- `analise-digital.md` - Site, SEO, redes sociais, app mobile
- `analise-competitiva-digital.md` - Comparações com O Boticário, Época, etc.
- `analise-produtos.md` - Categorias, marcas, preços
- `ferramentas-e-metricas.md` - Todos os dados de Google Trends, SimilarWeb, etc.

### 4. Consolide no Deck Final

O arquivo principal é `03-documentos-finais/deck-aprendizados-sumire.md`:
- Este é o documento que reúne TODOS os aprendizados
- Preencha conforme avança nas fases
- Ao final, terá um documento completo de pesquisa
