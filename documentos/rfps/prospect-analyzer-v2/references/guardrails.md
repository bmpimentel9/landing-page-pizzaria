# Guardrails - O Que NÃO Fazer

## CRÍTICO: Erros que Invalidam a Apresentação

### 1. ❌ NUNCA Invente Dados

**Proibido**:
```
❌ "O site recebe 47.832 visitas por mês"
❌ "A taxa de conversão é de 2,3%"
❌ "O CAC estimado é de R$ 45,00"
```

**Correto**:
```
✅ "Tráfego estimado entre 30-50K visitas/mês (SimilarWeb)"
✅ "Benchmark do setor: conversão média de 1-3%"
✅ "Dados de CAC não disponíveis publicamente"
```

**Por quê**: Cliente pode questionar a fonte. Dados falsos destroem credibilidade.

---

### 2. ❌ NUNCA Assuma Redes Sociais Sem Verificar

**Proibido**:
```
❌ Buscar "marca instagram" e assumir que o primeiro resultado é oficial
❌ Usar métricas de um perfil sem verificar se é da empresa
❌ Listar redes que não foram confirmadas
```

**Correto**:
```
✅ Verificar se a bio menciona a marca
✅ Verificar se o link no perfil aponta para o site
✅ Se houver dúvida: "Instagram: não identificado com certeza"
```

**Por quê**: Existem perfis falsos, fã pages, e perfis de outras empresas com nome similar.

---

### 3. ❌ NUNCA Ultrapasse 10 Slides

**Proibido**:
```
❌ 15 slides "para ser mais completo"
❌ Slides de transição desnecessários
❌ Múltiplos slides para o mesmo tema
```

**Correto**:
```
✅ Exatamente 10 slides ou menos
✅ Cada slide com 1 mensagem clara
✅ Menos é mais - foco em insights acionáveis
```

**Por quê**: Consultoria gratuita deve ser rápida e impactante. Cliente perde interesse após 10 slides.

---

### 4. ❌ NUNCA Omita Fontes

**Proibido**:
```
❌ "O tráfego está crescendo" (sem fonte)
❌ Tabela de keywords sem indicar origem dos dados
❌ Gráficos sem legenda de fonte
```

**Correto**:
```
✅ "Fonte: SimilarWeb (dados públicos), consulta em Jan/2024"
✅ "Fonte: Pesquisa SERP + dados públicos SEMrush"
✅ Todo slide com rodapé indicando fonte
```

**Por quê**: Sem fonte = sem credibilidade = cliente não confia = não fecha.

---

### 5. ❌ NUNCA Use Cores Fora da Paleta

**Proibido**:
```
❌ Azul, verde, roxo aleatórios
❌ Gradientes que não são V4
❌ Texto escuro em fundo escuro
```

**Correto**:
```
✅ Primário: #C41E3A (Vermelho V4)
✅ Secundário: #8B0000 (Vermelho escuro)
✅ Acento: #FF6B6B (Coral)
✅ Texto: #FFFFFF (Branco)
```

**Por quê**: Identidade visual é parte da proposta de valor. Apresentação precisa parecer V4.

---

## IMPORTANTE: Erros que Reduzem a Qualidade

### 6. ⚠️ Evite Slides Genéricos

**Problema**:
```
⚠️ "Melhore seu SEO" (sem especificar como)
⚠️ "Invista em mídia paga" (sem dados de demanda)
⚠️ "Use redes sociais" (sem análise do que já existe)
```

**Solução**:
```
✅ "Otimize para as keywords [X, Y, Z] que têm 10K buscas/mês"
✅ "Google Ads em [keywords] com CPC médio de R$2,50"
✅ "Instagram tem 15K seguidores mas posts 3x/sem. LinkedIn subutilizado."
```

---

### 7. ⚠️ Evite Jargão Sem Explicação

**Problema**:
```
⚠️ "Implementar GTM com datalayer"
⚠️ "Estratégia de GEO para LLMs"
⚠️ "CDP com atribuição multi-touch"
```

**Solução**:
```
✅ "Implementar sistema de tags (GTM) para medir conversões"
✅ "Aparecer em respostas de IA como ChatGPT (GEO)"
✅ "Sistema que identifica qual canal trouxe a venda"
```

---

### 8. ⚠️ Evite Tabelas Muito Grandes

**Problema**:
```
⚠️ 50 keywords em uma tabela
⚠️ Texto pequeno demais para ler
⚠️ Scroll mental necessário
```

**Solução**:
```
✅ Máximo 15-20 keywords por slide
✅ Fonte mínima 14pt em tabelas
✅ Se precisar de mais dados, mencionar: "Análise completa disponível"
```

---

### 9. ⚠️ Evite Promessas Específicas de Resultado

**Problema**:
```
⚠️ "Garantimos aumento de 50% em vendas"
⚠️ "ROI de 500% em 3 meses"
⚠️ "Primeiro lugar no Google em 30 dias"
```

**Solução**:
```
✅ "Potencial de melhoria estimado com base em benchmarks"
✅ "Empresas similares alcançaram X após implementação"
✅ "Resultados dependem de execução e fatores de mercado"
```

**Por quê**: Promessas específicas podem ser cobradas. Use benchmarks, não garantias.

---

### 10. ⚠️ Evite Críticas Excessivas

**Problema**:
```
⚠️ "O site é terrível"
⚠️ "Estratégia completamente errada"
⚠️ "Concorrentes são muito melhores"
```

**Solução**:
```
✅ "Identificamos oportunidades de melhoria em X"
✅ "Ajustes em [área] podem trazer resultados significativos"
✅ "Análise competitiva mostra gaps que podem ser explorados"
```

**Por quê**: Objetivo é conquistar cliente, não ofender. Foque em oportunidades, não falhas.

---

## QUALIDADE: Checklist Final

### Antes de Entregar, Verificar:

**Dados**:
- [ ] Todos os números têm fonte citada
- [ ] Nenhum dado foi inventado
- [ ] Estimativas são conservadoras
- [ ] Benchmarks são de fontes confiáveis

**Visual**:
- [ ] Exatamente 10 slides ou menos
- [ ] Cores da paleta V4
- [ ] Texto legível (contraste adequado)
- [ ] Pelo menos 1 elemento visual por slide

**Conteúdo**:
- [ ] Cada slide tem 1 insight claro
- [ ] Máximo 6 bullet points por slide
- [ ] Jargão explicado
- [ ] Tom construtivo (oportunidades, não críticas)

**Técnico**:
- [ ] Redes sociais verificadas
- [ ] URLs corretas
- [ ] Nomes de empresa/marca corretos
- [ ] Data da análise incluída

## Respostas para Situações Comuns

### "Não encontrei dados de tráfego"

```
✅ "Dados de tráfego não disponíveis publicamente para este domínio. 
    Baseado em benchmarks do setor [X], estimamos entre Y-Z visitas/mês."
```

### "Não tenho certeza se a rede social é oficial"

```
✅ "Instagram identificado: @handle (verificação pendente). 
    Recomendamos confirmar antes de usar como referência."
```

### "Concorrentes são difíceis de identificar"

```
✅ "Análise de concorrência baseada em keywords transacionais. 
    Principais players identificados: [lista]. 
    Mapeamento completo disponível em análise aprofundada."
```

### "Dados de CRM não são visíveis"

```
✅ "CRM não identificado via análise externa. 
    Recomendação baseada em melhores práticas do setor."
```

## Validação Visual Obrigatória

Antes de entregar o deck, SEMPRE:

1. **Converter para imagens**:
   ```bash
   soffice --headless --convert-to pdf output.pptx
   pdftoppm -jpeg -r 150 output.pdf slide
   ```

2. **Verificar cada imagem**:
   - Texto cortado?
   - Elementos sobrepostos?
   - Cores incorretas?
   - Gráficos renderizados?

3. **Corrigir problemas** antes de entregar

**Não entregar deck sem validação visual!**
