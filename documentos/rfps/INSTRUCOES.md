# Instruções de Uso - Prospect Analyzer V2

## Sobre esta pasta

Esta pasta contém a skill **Prospect Analyzer V2** para análise de prospects B2B da V4 Company.

## Como funciona

Quando você me pedir para executar o trabalho nesta pasta e fornecer um site/URL:

1. **Verificação de pasta**: Vou verificar se já existe uma pasta com o nome do domínio do cliente
2. **Criação de pasta**: Se não existir, vou criar uma nova pasta com o nome do domínio
3. **Confirmação**: Vou perguntar se posso prosseguir com a análise
4. **Execução**: Após confirmação, executo a análise completa e gero o PPTX

## Formato de uso

```
Execute a análise para www.exemplo.com.br
```

ou

```
Analise o prospect www.exemplo.com.br
```

## Estrutura de pastas

```
/rfps
├── INSTRUCOES.md (este arquivo)
├── prospect-analyzer-v2/ (skill)
│   ├── SKILL.md

├── www.cliente2.com.br/ (pasta do cliente 2)
│   └── prospect-analysis-cliente2-YYYY-MM-DD.pptx
└── ...
```

## Output gerado

Para cada análise, será gerado um deck PPTX profissional com **10 slides**:

1. **Capa** - Apresentação V4 Company
2. **Radar de Maturidade** - Score geral e por dimensão
3. **Diagnóstico de Dados** - Tags, pixels, analytics
4. **Demanda de Mercado** - Keywords transacionais
5. **Análise de Concorrência** - Top 3 concorrentes
6. **SEO & GEO** - Visibilidade orgânica e em IAs
7. **CRM & Automação** - Relacionamento e régua de emails
8. **Redes Sociais** - Panorama das redes verificadas
9. **Plano de Ação** - 5 quick wins priorizados
10. **Próximos Passos** - CTA para reunião

## Importante

- Todos os dados são baseados em **fontes públicas verificáveis**
- Redes sociais são **verificadas** antes de serem incluídas
- Fontes são citadas em cada slide
- Cores seguem a paleta oficial V4 Company (Vermelho #C41E3A)
