# PRD - Landing Page Pizzaria

## 1. Visão do Projeto

**Nome:** Pizzaria Sabor & Delivery - Landing Page de Captura

**Objetivo:** Criar uma landing page criativa para capturar email e WhatsApp de potenciais clientes, enviando cardápio e promoções.

---

## 2. Público-Alvo

- Pessoas que procuram pizza delivery
- Faixa etária: 18-45 anos
- Localização: área de delivery da pizzaria

---

## 3. Funcionalidades Principais

### 3.1 Captura de Email
- Formulário chamativo na hero section
- Offer: "Receba 15% OFF na primeira compra"
- Validação de email
- Feedback visual após envio

### 3.2 Captura de WhatsApp ( pós-email)
- Segunda etapa após email confirmado
- Offer: "Receba nosso cardápio completo no WhatsApp"
- Campo com máscara para número
- Redirecionamento para link do WhatsApp API

### 3.3 Fluxo do Usuário
```
Landing → Email (15% OFF) → WhatsApp (Cardápio) → Redirecionamento WhatsApp
```

---

## 4. Estrutura da Página

### Hero Section
- Imagem apetitosa de pizza
- Headline criativa
- Subheadline com benefit
- Formulário de email

### Seção de Diferenciais
- Pizza artesanal
- Entrega rápida
- Ingredientes frescos

### Depoimentos
- Clientes satisfeitos

### Footer
- Redes sociais
- Informações de contato

---

## 5. Criatividade & Diferenciais

- **Animação:** Entrada suave dos elementos
- **Cores:** Vermelho (appetite), dourado (premium), branco
- **Microinterações:** Hover nos botões, sucesso na captura
- **Copy emocional:** Foco em momentos de convívio e satisfação

---

## 6. Tech Stack

- HTML/CSS/JS (ou Next.js/Vite)
- Integração com API de email (opcional)
- Link WhatsApp API com mensagem automática

---

## 7. Métricas de Sucesso

- Taxa de conversão email: > 30%
- Taxa de conversão WhatsApp (após email): > 50%
- Tempo na página: > 30 segundos
